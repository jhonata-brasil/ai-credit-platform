# Termo de referência — linha de crédito empresarial

O produto é uma linha de crédito para capital de giro e investimento.

Prazo típico: 12 a 36 meses.

Documentos de suporte: cartão CNPJ, faturamento declarado e política interna.

O analista deve recuperar este termo para redigir a descrição do item da proposta.
